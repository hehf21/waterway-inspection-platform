# 培训速查卡（一页纸 · 打印发给检查人员/企业经办人）

## 一、检查人员：登记一次检查（约 3 分钟）

1. 登录 → 「登记检查」→ 选企业 → 选检查表模板
2. 逐项点结果：大多数没问题就点 **「未选的全部填"符合"」**，再把不符合的项单独改掉
3. 不符合项会**自动带出问题卡**：补全"问题描述+整改要求"，点 **15天/30天** 快捷填整改期限
4. 结论选"责发整改"（有问题）或"未发现问题" → 「保存登记」
5. 详情页点 **「下发（企业可见）」** → 企业才能看到
6. 连续检查多家？用 **「保存并登记下一家」**
7. 手机现场：导航「📱现场登记」，逐项大按钮点选，支持**语音输入**和拍照；中途退出不丢（自动暂存）

## 二、企业经办人：整改反馈（约 2 分钟）

1. 登录 → 工作台「待我整改」→ 点「去整改」（直达反馈框）
2. 反馈框旁边就是**整改要求原文**，照着写"原因分析+整改措施"
3. 传**整改照片**（和检查现场照片会自动左右对比，复核好通过）
4. 写一半有事？**草稿自动保存**，回来接着写
5. 确有困难？点「申请延期」填新期限+理由，等监管人员审批
6. 逾期了页面会有红条提醒——别拖

## 三、检查人员：复核归档（约 2 分钟）

1. 详情页「✔ 复核」→ 通过或退回（退回要写意见，企业重新整改）
2. 问题标题处看 **整改进度 n/m**——每个问题都要单独反馈+复核
3. 双方**手写签字**（✍ 手写签字确认，可用鼠标/触屏签）
4. 「📦 归档并锁定」→ 之后内容不可改（要改走"更正留痕"）
5. 「🖨 打印检查表」一式两份，签字栏带手写签名，直接入卷

## 四、管理员：每月例行

| 事项 | 位置 |
|---|---|
| 月度考核汇总表（可套上级模板） | 统计分析 → 月度汇总 → 导出 Excel |
| 督办逾期企业 | 工作台"逾期最多企业"→ 督办台账 |
| 每日提醒（含备份状态） | 消息提醒 / 群机器人自动推送 |
| 数据体检 | 维护人员跑 `python db_maintenance.py check` |

## 五、常见问题

| 问题 | 处理 |
|---|---|
| 页面点了没反应/排版乱 | 换 Edge/Chrome，或 360/QQ 浏览器切**极速模式**（页面会弹红条提示） |
| 忘记密码 | 找管理员重置（重置后需改密，其他登录自动失效） |
| 想改已归档的记录 | 仅管理员「更正留痕」解除锁定，改动全程留痕 |
| 手机上想发检查表给企业 | 详情页「下载 现场检查记录 PDF」发微信即可 |
